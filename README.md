# Aetherium

Mod para Minecraft 1.16.5 con Forge 36.2.42.

Requiere JDK 8. Compilar con `gradlew build` (Windows: `gradlew.bat build`). El JAR se genera en `build/libs/`.

Curios es opcional; los accesorios pueden equiparse en los slots Necklace y Ring cuando Curios está instalado. Las habilidades de uso directo funcionan sin Curios.

Estado: compilación automática en validación; no considerar estable hasta completar la compilación y pruebas dentro del juego.
